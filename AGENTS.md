# Instrucciones para agentes

Para escribir o editar contenido de este blog, seguir la guía de voz, estructura y convenciones de
[`AGENT.md`](AGENT.md).

Markdown es el formato estándar del blog. El contenido nuevo debe escribirse en archivos `.md` y,
cuando se migre una página existente, debe reemplazarse su versión RST por Markdown conservando su
slug y su URL pública.
